# Steam Translate

Кнопка **«Перевести»** (Google Translate) для страниц магазина и сообщества в клиенте Steam для Windows.

Клиент Steam построен на Chromium (CEF). Если запустить его с отладочным портом, к нему можно подключиться по Chrome DevTools Protocol и встроить в страницы свою кнопку. Именно это делает `SteamTranslate.exe`: небольшая программа в трее, без установки.

## Как пользоваться

1. Скачайте `SteamTranslate.exe` из [последнего релиза](../../releases/latest) и запустите. Появится иконка в трее.
2. Steam должен быть запущен с флагом `-cef-enable-debugging`. Если он запущен без него, через 20 секунд exe покажет уведомление; нажмите на него, либо выберите в меню иконки **«Перезапустить Steam с кнопкой перевода…»**. Steam закроется штатно и запустится заново.
3. Откройте страницу магазина или сообщества. Справа внизу появится кнопка **🌐 Перевести**. После перевода она превращается в **↩ Оригинал**.
4. Галочка **авто** переводит каждую открытую страницу сразу.

Меню иконки в трее: язык перевода (по умолчанию русский, ещё 12 языков), запуск вместе с Windows, перезапуск Steam, лог.

## Как это работает

- Находит порт отладки среди портов процессов Steam (`steam.exe`, `steamwebhelper.exe`), подключается по DevTools Protocol и добавляет скрипт [`inject.js`](src/inject.js) в вкладки `*.steampowered.com` и `*.steamcommunity.com`.
- Текст переводится **абзацами**, как в расширении [Translate Web Pages](https://github.com/FilipePS/Traduzir-paginas-web): все текстовые узлы одного блока уходят в Google одним HTML-фрагментом с метками `<a i=N>`, так что Google видит предложение целиком, а перевод раскладывается обратно по узлам. Контент, подгруженный позже (отзывы, «показать ещё»), переводится автоматически.
- Запросы идут в `translate-pa.googleapis.com/v1/translateHtml`, тот же сервис, что встроен в Chrome. Публичный ключ сервиса берётся из скрипта самого Google Translate при первом переводе.

## Ограничения

- Только Windows, только клиент Steam для ПК (не мобильное приложение).
- Сервис Google неофициальный и без гарантий. Если Google изменит адрес скрипта с ключом, перевод перестанет работать до обновления программы.
- Порт отладки доступен любой программе на этом компьютере (только локально, `127.0.0.1`). Пока Steam запущен с флагом, это так.
- В предложениях с большим количеством тегов внутри Google иногда переставляет слова; метки привязывают их к прежним местам.

## Сборка

Нужен .NET SDK (проект целится в .NET Framework 4.8, который уже есть в Windows 10/11):

```powershell
dotnet build src/SteamTranslate.csproj -c Release
# результат: src/bin/Release/net48/SteamTranslate.exe
```

GitHub Actions собирает exe при каждом коммите в `main` (артефакт `SteamTranslate.exe` без zip) и выпускает релиз по тегу `v*`:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

Лог и настройки: `%LOCALAPPDATA%\SteamTranslate\log.txt`, `%APPDATA%\SteamTranslate\settings.json`.
